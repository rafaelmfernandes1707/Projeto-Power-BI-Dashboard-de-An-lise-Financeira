# 📊 Dashboard de Análise Financeira | Power BI

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um Dashboard de Análise Financeira utilizando Power BI, com o objetivo de visualizar e analisar indicadores financeiros, permitindo acompanhar receitas, despesas e margens de forma interativa.

## 🛠️ Ferramentas utilizadas

- **Power BI Desktop:** desenvolvimento e visualização dos dashboards.
- **Power Query:** preparação e transformação dos dados.
- **DAX:** criação e análise de indicadores financeiros.

## 📈 Principais indicadores

O dashboard apresenta os seguintes indicadores:

- **Total de Receitas:** acompanhamento dos valores arrecadados.
- **Total de Despesas:** monitoramento dos gastos.
- **Margem:** análise da relação entre receitas e despesas.
- **Principais Segmentos:** identificação e classificação dos segmentos analisados.
- **Receitas por Componente:** comparação dos valores de receitas por categoria.
- **Despesas por Componente:** análise da distribuição das despesas.
- **Análise Anual:** comparação dos resultados financeiros ao longo dos anos.

## 🎯 Objetivo do projeto

Desenvolver habilidades em Business Intelligence, análise de dados e visualização de indicadores financeiros, aplicando recursos do Power BI para transformar dados em informações relevantes para a tomada de decisões.
